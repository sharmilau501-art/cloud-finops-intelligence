# Cloud Infrastructure Cost Intelligence: Power BI

Build `FinOps_Infrastructure_Intelligence.pbix` using `data/powerbi/*.csv`
created by `python -m finops.phase6_export`.

**Sources are synthetic.** The dashboard is a portfolio demonstration, not
PlayStation operational data, nor a production forecast.

See `docs/phase6-powerbi.md` for relationships, DAX measures, report pages,
and screenshot instructions. Add locally created dashboard screenshots here
under `dashboards/screenshots/`.
